## Prompt template

Use case: precise-object-edit. Edit this game UI icon into a finished icon with its label baked into the SAME transparent PNG. Preserve the illustrated object, colors, bold cartoon outlines and glossy cel shading. Recompose into a compact square icon lockup: large object above, exact label immediately below touching/slightly overlapping the bottom edge of object, zero empty gap. Label is heavy bold condensed sans serif, bright white with thick dark navy outline and tiny dark drop shadow, large and easily readable at small sidebar size. One horizontal line, not curved. Text should span almost full icon width. Object uses upper 78%, text lower 18%, 4% safe padding. No panel or banner behind text, no extra decoration. Truly transparent background. Exact text: "<label>".
