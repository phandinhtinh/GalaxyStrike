## Generation prompt

Use case: stylized-concept. Asset type: production game UI sprite, empty horizontal progress-track frame for a portrait pixel-art space shooter named GalaxyStrike. Generate ONE isolated very wide thin HUD progress bar chassis, aspect ratio about 9:1, straight-on flat orthographic view. Cyan blue glowing beveled metallic pixel-art frame with small angular sci-fi endcaps, dark navy recessed EMPTY interior track. Match arcade blue/cyan pixel-art spaceship HUDs. Clean pixel edges, restrained glow, transparent background outside the bar. Bar is empty and unfilled; no red. No words, no letters, no numbers, no wave markers, no symbols, no icons: all text, progress fill, wave markers and finish flag will be live Unity UI overlays. Uniform interior track along full length, large unobstructed center. The single bar spans almost the full width of the image with minimal transparent margins. Prefer a very wide 1536 by 256 canvas. No mockup, no scene, no multiple assets, no drop shadow outside the sprite.
